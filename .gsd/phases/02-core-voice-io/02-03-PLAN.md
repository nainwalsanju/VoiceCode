<objective>
Set up Whisper for local speech-to-text transcription.

Purpose: Enable local STT without cloud dependencies for privacy.
Output: Backend can transcribe audio to text using Whisper.
</objective>

<context>
@PROJECT.md
@ROADMAP.md
</context>

<tasks>
  <task type="auto">
    <name>Install Whisper</name>
    <action>
      1. Add whisper to backend/requirements.txt
      2. Run: pip install openai-whisper
      3. Or use faster-whisper for better performance: pip install faster-whisper
      4. Verify installation
    </action>
    <verify>
      - Whisper package installed
      - Can import whisper or faster_whisper
    </verify>
    <done>Whisper installed</done>
  </task>

  <task type="auto">
    <name>Create STT service module</name>
    <action>
      1. Create backend/services/stt_service.py
      2. Implement Whisper wrapper class
      3. Add methods: load_model(), transcribe(), get_available_models()
      4. Add model caching for performance
    </action>
    <verify>
      - STT service module created
      - Can load Whisper model
    </verify>
    <done>STT service module created</done>
  </task>

  <task type="auto">
    <name>Implement STT transcription endpoint</name>
    <action>
      1. Create backend/routes/stt.py
      2. Add POST /stt/transcribe endpoint
      3. Accept audio file (multipart/form-data)
      4. Return JSON: { text, language, duration }
      5. Add error handling
    </action>
    <verify>
      - /stt/transcribe endpoint exists
      - Returns transcribed text
    </verify>
    <done>STT endpoint implemented</done>
  </task>

  <task type="auto">
    <name>Test STT transcription</name>
    <action>
      1. Start backend server
      2. Record or provide test audio file
      3. Call /stt/transcribe with audio
      4. Verify text is returned
    </action>
    <verify>
      - STT transcribes audio to text
      - Transcription is accurate
    </verify>
    <done>STT transcription working</done>
  </task>
</tasks>

<success_criteria>
- Whisper installed and working
- /stt/transcribe returns transcribed text
- Can handle different audio formats
- Transcription completes in reasonable time
</success_criteria>

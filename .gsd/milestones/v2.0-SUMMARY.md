## Concerns
- **Environment Management:** Relying heavily on local Python versions rather than encapsulated Docker networks may cause cross-system compatibility issues down the line.
- **Latency Overheads:** Orchestrator currently pipes transcriptions -> LLMs -> TTS, potentially stacking latency beyond the 200ms bounds under severe local hardware constraints.

## Recommendations
1. Package the Python sub-process efficiently within the Tauri build payload so users don't need manual environments.
2. Abstract TTS generation to support edge-caching or parallel streaming hooks early in the LLM token response.
3. Invest in an automated regression test suite using Playwright to handle UI/UX state matrices across Agent changes.

## Technical Debt to Address
- [ ] Migrate raw edge-tts CLI processes into robust Python bindings or web scraping equivalents depending on network access.
- [ ] Build a robust error fallback state UI for TTS streams that fail abruptly to prevent silent timeouts on the frontend.

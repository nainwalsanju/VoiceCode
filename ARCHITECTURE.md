# Architecture

> Generated by /map on 2026-03-04

## Overview
VoiceCode is a desktop application combining a Tauri-based React frontend with a Python FastAPI backend for AI-driven voice commands.

## System Diagram
```text
[User] <--> [Tauri App Shell] <--> [React Frontend (UI)]
                                      | (HTTP / WebSocket)
                                      v
                             [FastAPI Backend]
                               /      |      \
                      [STT Service] [LLM] [TTS Service]
```

## Components

### Frontend
- **Purpose:** User interface, global hotkey listening, state management.
- **Location:** `src/`
- **Dependencies:** React, Zustand, TailwindCSS, Tauri APIs.

### Backend
- **Purpose:** Process audio streams, transcribe speech, route commands, and synthesize voices.
- **Location:** `backend/`
- **Dependencies:** FastAPI, edge-tts, faster-whisper, structlog.

### Tauri Shell
- **Purpose:** OS-level integration, global shortcuts, window management.
- **Location:** `src-tauri/`

## Data Flow
1. User activates voice recording via global shortcut (Tauri).
2. Frontend records audio and streams it via WebSocket to FastAPI backend.
3. Backend processes audio through STT (faster-whisper/moonshine).
4. Text is passed to LLM for command resolution or conversational response.
5. Response is passed to TTS and streamed back to Frontend.
6. Frontend plays audio and updates UI state.

## Conventions
- **Naming:** CamelCase for React components, snake_case for Python backend.
- **Structure:** Modular frontend (`components`, `hooks`, `stores`). Route/service split in backend (`routes`, `services`).
- **Testing:** Playwright/Vitest for frontend. Python backend lacks comprehensive test suite.
